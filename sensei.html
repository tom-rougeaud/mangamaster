Les clans

Comment jouer le Sensei ?

Le Sensei joue depuis son propre téléphone, pas depuis cet écran : cliquez sur « Afficher le code Sensei » (il se masque seul au bout de 10 s) et suivez la consigne.

Je n’ai qu’un seul appareil

Le Sensei répond en secret : si vous jouez sur l’écran projeté, tout le monde voit vos réponses. Trois solutions :

  1. Écran étendu : faites glisser une fenêtre « joueur » sur l’écran non projeté.
  2. Masquer l’écran (bouton en haut à droite) : plus rien n’est projeté le temps de répondre ; les apprenti(e)s continuent sur leurs téléphones. Réaffichez pour la correction.
  3. Plus simple : passez en Duel de clans à deux clans ennemis. Vous (Sensei) rejoignez le clan 1 avec votre téléphone, tous les autres rejoignent le clan 2.

    Aide rapide

    1. Choisir : le mode de jeu et les réglages (types de questions, difficulté, temps de lecture, points), puis les thèmes à jouer, rangés par univers. Cochez un thème, un univers entier, ou tentez « Surprends-moi ».
    2. Vérifier : les questions sont tirées au sort parmi les thèmes cochés. Une question déjà jouée avec ce navigateur ne revient qu’une fois toutes les autres épuisées. Vous pouvez remplacer, retirer ou réordonner (réponses masquées tant que vous ne cochez pas « Afficher les réponses »).
    3. Ouvrir le dojo : les apprenti(e)s vont sur la page joueur (QR code ou adresse), tapent le code et leur pseudo (30 maximum).
    4. Duel de clans : chaque apprenti(e) glisse son jeton dans un clan ; vous pouvez renommer les clans et déplacer les joueurs.
    5. Apprenti(e)s VS Sensei : « Afficher le code Sensei » donne le code à taper sur votre téléphone pour jouer contre le groupe.
    6. Jouer : les règles s’affichent, puis les questions. « Joueurs » permet de renommer, d’exclure ou de faire entrer un retardataire (QR code). « +30 s » rallonge, « Écourter » passe directement aux gagnants.

    Plusieurs dojos peuvent être ouverts en même temps sur des ordinateurs différents : chaque dojo a son propre code.
